# Mockup

File HTML statici esportati dal canvas di design. Non si aprono correttamente nel browser (manca il runtime del canvas e i valori `{{accent}}` non vengono sostituiti: vale `#FFCB45`).
Servono come riferimento leggibile: struttura delle schermate, gerarchia, spaziature, raggi e colori sono tutti scritti negli attributi `style`.
I riquadri grigi delle carte sono segnaposto: nell'app vera ci vanno le immagini TCGdex.

**Barra di navigazione:** fa fede quella di `Home.html`, `Profilo.html` e `StatiBackup.html` (avatar tondo dell'account Google con pallino di stato del backup). Nelle altre schermate la barra è di una versione precedente (avatar quadrato giallo con l'iniziale): usare comunque il componente `Nav` unico.
Il logo di Google nel pulsante di `AccessoGoogle.html` è un segnaposto: il pulsante vero lo disegna Google Identity Services.
